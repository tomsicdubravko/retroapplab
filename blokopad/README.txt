BLOKOPAD v1.5 — paket za objavu

Uploadati svih šest datoteka iz ovog foldera:
index.html, favicon.svg, icon-192.png, icon-512.png, og-image.png, README.txt.

U postojećem GitHub repozitoriju RetroAppLab stranice napraviti folder
blokopad unutar izvora koji GitHub Pages već objavljuje (korijen ili docs,
ovisno o postojećim postavkama; kod Actions objave unutar objavljenog artefakta).
U taj folder smjestiti sadržaj paketa, bez dodatnog blokopad-release podfoldera.
Ne mijenjati postojeće postavke Pages, domenu ili CNAME.

Konačna adresa: https://retroapplab.com/blokopad/
Slika za dijeljenje: https://retroapplab.com/blokopad/og-image.png

Nakon objave provjeriti: splash → izbornik → igra; povlačenje i rotaciju;
zvuk, glasnoću i spremanje postavki; upute; Game Over i novu igru;
RetroAppLab poveznice; prikaz na mobitelu i računalu.
U konzoli i mrežnim zahtjevima provjeriti da nema grešaka ili 404 odgovora.
Otvoriti sve ikone i sliku za dijeljenje preko javnih adresa, provjeriti
favicon te prikaz dijeljenja (servisi mogu zadržati staru sliku u predmemoriji).

Original blokopad-v1.5.html nije izmijenjen. Paket nije automatski objavljen.
